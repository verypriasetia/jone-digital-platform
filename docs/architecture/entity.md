# Entity Model

**Status:** Draft

**Versi:** 0.1

---

## Apa itu Entity Model?

Entity Model adalah daftar seluruh data utama (entity) yang akan dikelola oleh Jone Digital Platform (JDP).

Dokumen ini membantu kita mengetahui data apa saja yang akan disimpan oleh sistem sebelum merancang database.

---

## Daftar Entity

### Core

- User
- Role
- Media
- Settings
- Audit Log

### Content

- Berita
- Pengumuman
- Agenda
- Galeri
- Banner
- Dokumen
- Halaman

### Village

- Profil Desa
- Perangkat Desa
- Pemerintahan Desa
- Dusun
- RT
- RW
- Lembaga Desa
- Potensi Desa
- APBDes

### Service

- Statistik
- Surat
- Pengaduan

---

## Catatan

Setiap entity akan dibahas pada dokumen terpisah sebelum dibuat menjadi tabel database.

Entity yang tercantum dalam dokumen ini merupakan dasar penyusunan struktur data JDP.
